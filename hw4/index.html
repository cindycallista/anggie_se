Small-team playbook

One short branch.
One reviewed change.

A lightweight GitHub Flow keeps the main branch safe without slowing down a small team.

main
feature/search
startcommitreviewmerge
01

Start from a clean main

Update the local repository before creating work.

git switch main
git pull --ff-only
git switch -c feature/search
02

Commit one useful unit

Stage intentionally and describe the result, not the activity.

git add src/search.js test/search.test.js
git commit -m "Add title search"
03

Push and open a pull request

Explain purpose, testing, and screenshots when the interface changes.

git push -u origin feature/search
gh pr create --fill
04

Review, merge, clean up

Resolve feedback, use squash merge, then remove the old branch.

gh pr merge --squash --delete-branch
git switch main
git pull --ff-only

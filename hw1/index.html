NetProbe

A dependency-free HTTP command-line client for inspecting APIs, following redirects, posting data, and saving responses.

terminal — node 18+
$ node netprobe.mjs -i -L https://example.com HTTP 200 OK content-type: text/html <!doctype html>...

Request controls

Choose a method, repeat headers, attach a body, and set an abort timeout.

Response controls

Show metadata in the terminal or write the body directly to a file.

Redirect policy

Redirects remain visible by default. Add -L when automatic following is required.

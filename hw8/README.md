# Week 8 / Settle Sheet

洪英佩 — 111211147

[Open the live project](https://anggie0707.github.io/_se/hw8/)

Settle Sheet solves a common group problem: one person pays for dinner, another pays for transport, and not every expense includes everyone. The page calculates each member's exact balance and turns it into a short transfer list.

What it does:

- manages group members;
- records a payer, amount, description, and selected participants;
- divides every cost only among the people who joined it;
- calculates positive and negative balances;
- reduces the result to direct person-to-person transfers;
- saves the ledger locally and exports a text summary.

The project is plain HTML, CSS, and JavaScript. It can be reviewed from GitHub Pages without Docker, a backend, or a build step.

# Week 3 / FreshFirst

[Open the pantry](https://anggie0707.github.io/_se/hw3/)

FreshFirst answers one practical question: which stored food should be used next? Items are ordered by date, can be narrowed by storage location, and may be marked as consumed or removed.

I used this project to practice date comparison, filtering, generated interface elements, CSV export, and saving state inside the browser.
